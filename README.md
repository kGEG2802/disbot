# disbot — міст Discord → Telegram

Пересилає повідомлення з обраних каналів **Discord** у ваш **Telegram-бот**, щоб
не пропустити важливі повідомлення, коли push-сповіщення Discord на телефоні
не приходять.

```
Discord (канали)  ──►  disbot (читає нові повідомлення)  ──►  Telegram-бот  ──►  ваш телефон
```

---

## ⚠️ Важливе попередження

Оскільки бота **не можна додати на чужі сервери**, disbot підключається до Discord
під **вашим користувацьким акаунтом** (user-token, він же «self-bot»).

> **Це порушує [Правила користування Discord](https://discord.com/terms) і
> теоретично може призвести до блокування акаунта.** Жодних гарантій немає.
> Використовуйте на власний ризик.

Щоб знизити ризик, disbot працює **лише в режимі читання**: він читає й пересилає
повідомлення і **нічого не робить від вашого імені** — не пише, не реагує, не
вступає на сервери, не виконує жодних дій. Обсяг трафіку — мінімальний.

Якщо у вас є сервер, де ви адміністратор, **набагато безпечніше** використати
звичайного офіційного бота Discord замість self-bot — напишіть про це, і я
адаптую код.

---

## Можливості

- Пересилання всіх повідомлень з обраного списку каналів (режим за замовчуванням).
- Альтернативні режими: лише **згадки/відповіді вам** або лише за **ключовими словами**.
- Обмеження по серверах (гільдіях) і чорний список каналів.
- Пересилання приватних повідомлень (DM).
- Гарне форматування: сервер › канал, автор, текст, вкладення, пряме посилання на повідомлення.
- Стійкість: черга та повтори з урахуванням лімітів Telegram, авто-перепідключення, plain-text fallback.
- Тестове повідомлення в Telegram при старті, щоб переконатися, що все працює.

## Налаштування

### 1. Встановити залежності

```bash
git clone <repo-url>
cd disbot
npm install
```

### 2. Створити Telegram-бот і дізнатися chat_id

1. У Telegram напишіть **[@BotFather](https://t.me/BotFather)** → `/newbot` → отримайте **`TELEGRAM_BOT_TOKEN`**.
2. Напишіть будь-яке повідомлення вашому новому боту (щоб він міг вам відповідати).
3. Дізнайтеся свій **`TELEGRAM_CHAT_ID`** одним зі способів:
   - напишіть боту **[@userinfobot](https://t.me/userinfobot)** — він покаже ваш ID; або
   - відкрийте `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` після повідомлення боту й знайдіть `"chat":{"id": ...}`.

### 3. Дізнатися свій токен Discord

Це **ваш власний** токен акаунта:

1. Відкрийте Discord у браузері (https://discord.com/app) та увійдіть.
2. Натисніть `F12` → вкладка **Network** (Мережа).
3. У фільтрі введіть `/api` і клацніть будь-який запит до Discord.
4. У **Headers → Request Headers** знайдіть поле **`authorization`** — це і є ваш токен.

> Нікому не передавайте цей токен — він дає повний доступ до акаунта. Зберігайте лише у файлі `.env`.

### 4. Дізнатися ID каналів

1. У Discord: **Settings → Advanced → Developer Mode** → увімкнути.
2. ПКМ на каналі → **Copy Channel ID**.
3. Зберіть потрібні ID у змінну `WATCH_CHANNELS` (через кому).

### 5. Заповнити `.env`

```bash
cp .env.example .env
```

Відредагуйте `.env` (мінімум — токени, chat_id і список каналів):

```ini
DISCORD_TOKEN=ваш_discord_user_token
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=123456789
FORWARD_MODE=all
WATCH_CHANNELS=111111111111111111,222222222222222222
```

### 6. Запуск

```bash
npm start
```

Якщо все правильно, у Telegram прийде повідомлення «✅ disbot запущено».

## Параметри конфігурації

| Змінна               | За замовчуванням | Опис |
|----------------------|------------------|------|
| `DISCORD_TOKEN`      | —                | Ваш користувацький токен Discord. **Обов'язково.** |
| `TELEGRAM_BOT_TOKEN` | —                | Токен бота від @BotFather. **Обов'язково.** |
| `TELEGRAM_CHAT_ID`   | —                | Куди надсилати сповіщення. **Обов'язково.** |
| `FORWARD_MODE`       | `all`            | `all` — усі; `mentions` — лише згадки/відповіді вам; `keywords` — за ключовими словами. |
| `WATCH_CHANNELS`     | *(порожньо)*     | ID каналів через кому. Порожньо = усі видимі канали (шумно). |
| `WATCH_GUILDS`       | *(порожньо)*     | Обмежити певними серверами (ID гільдій через кому). |
| `IGNORE_CHANNELS`    | *(порожньо)*     | Канали, які ігнорувати (ID через кому). |
| `KEYWORDS`           | *(порожньо)*     | Ключові слова через кому (для `FORWARD_MODE=keywords`). |
| `IGNORE_SELF`        | `true`           | Не пересилати ваші власні повідомлення. |
| `IGNORE_BOTS`        | `false`          | Якщо `true` — не пересилати повідомлення ботів. |
| `INCLUDE_DMS`        | `true`           | Пересилати приватні повідомлення (DM). |
| `STARTUP_PING`       | `true`           | Надсилати тестове повідомлення при старті. |

## Запуск 24/7

Контейнер/ноутбук має працювати постійно, щоб бот ловив повідомлення. Варіанти:

**Docker (рекомендовано):**

```bash
docker compose up -d --build
docker compose logs -f      # дивитися логи
```

**Або** на VPS чи сервері через менеджер процесів, напр. `pm2`:

```bash
npm install -g pm2
pm2 start src/index.js --name disbot
pm2 save
```

## Як це влаштовано

- `src/index.js` — точка входу: завантажує конфіг, перевіряє Telegram, запускає Discord.
- `src/config.js` — читання та валідація налаштувань з `.env`.
- `src/discord.js` — підключення до Discord і обробка нових повідомлень.
- `src/filter.js` — рішення, чи пересилати повідомлення (режими, списки каналів).
- `src/format.js` — форматування повідомлення у HTML для Telegram.
- `src/telegram.js` — надсилання в Telegram з чергою, повторами та обробкою лімітів.

## Застереження

Цей проєкт надається «як є», для особистого використання. Self-bot порушує Правила
Discord; автор і код не несуть відповідальності за можливі наслідки для вашого
акаунта. Тримайте токени в секреті.
